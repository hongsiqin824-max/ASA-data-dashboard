# 鸿蒙 ROI 看板实施记录

## 目标

在现有 iOS ASA ROI 后台中增加独立鸿蒙视图，复用成熟的筛选、缓存、ROI 成熟度、详情和导出能力，同时保证两个平台的数据源、缓存和业务语义完全隔离。

## 已完成

1. 增加 `iOS / 鸿蒙` 平台切换和 URL 平台参数。
2. 后端用固定白名单绑定两张成品表，拒绝非法平台。
3. 鸿蒙按 `任务 / 子任务` 建模，使用真实下载、激活、注册、会员收入和充值收入字段。
4. 服务端缓存、浏览器缓存、每日明细、日期作用域和导出均加入平台维度。
5. 鸿蒙界面与导出隐藏源表不存在的广告收入及 iOS 安装拆分。
6. 表结构检查按平台使用不同必需字段清单。
7. SQL 查看入口按鸿蒙真实字段生成只读审计 SQL。
8. 完成真实数据、ROI 窗口、收益拆分和双端缓存隔离对账。
